# PickNest

购物清单：食材、日用品、衣服、书、木工材料……都放在一个 App 里，可以按清单看，也可以按商店看。去 Whole Foods 前打开「Whole Foods」，所有清单里要在那儿买的东西都在一页上。

- 网页 App（PWA），不需要编译，也不用上架 App Store；部署到 GitHub Pages 就能在 iPhone、iPad、Mac 上用，添加到主屏幕 / 程序坞后和普通 App 一样打开，没网也能用
- 数据保存在自己设备的浏览器里；开启同步后，另存一份到你自己的 GitHub 私有仓库（`pick-nest-data`），不经过任何第三方服务器
- 界面有简体中文、繁體中文（台灣）、English 三种；你写的名字、备注永远原样保存，不做简繁转换

> **V1 的功能都做好了，也做过一遍全面检查**（第 7 步）；**第二版的「食谱」「计划」也做好了**（第 8–12 步）；**第三版的「日历」和饮食记录也做好了**（第 13 步：记吃了什么、热量和营养素、目标；第 14 步：App 里带上了常见食材的营养数据表，见下面「营养数据」；第 15 步：没填每人份营养的食谱按食材用量自动估算，见下面「自动估算」；第 16 步把这三步一起检查了一遍，进度见 [docs/ROADMAP.md](docs/ROADMAP.md)）。下面写的就是现在的样子，做不到的事在最后的「已知限制」里。

> 首页「清单」，点进一张清单就能加东西、勾掉、改；能新建、改名、换图标和颜色、排顺序、归档、删除清单。「商店」页看每家店还要买几样（可以只看一张清单），点进一家店直接勾。在店里推着车时可以打开「屏幕常亮」（清单页、商店页右上角「⋯」里），边走边勾屏幕不会变暗。「搜索」一次搜所有清单（简体繁体互通）。「食谱」里记菜谱（食材可以整段粘贴进来自动拆开，可以拍一张成品图），一键把食材按人数加到清单上，常备品默认不加。「日历」里排一周吃什么，按几天的菜一起生成购物清单（每道菜的用量分开记，删掉一道菜清单上跟着减）；也记每天实际吃了什么、多少千卡和蛋白质 / 碳水 / 脂肪，和自己定的目标比；食谱没填营养的按食材用量自动估算（写「约」）。iPad 横放和 Mac 上左右两栏。「设置」里能换语言（简体 / 繁體 / English）和外观（自动 / 浅色 / 深色），管理商店和分类，开多设备同步（自己的 GitHub 私有仓库），导出备份、从备份恢复，在「最近删除」里找回删掉的东西。部署后添加到主屏幕，没网也能打开。

## 怎么用

iPhone 上底栏五个：**清单** ｜ **商店** ｜ **食谱** ｜ **日历** ｜ **设置**；点进一张清单、一家店、一道食谱、搜索、设置里的一项，是推进去的一页（左上角返回，不显示底栏）。iPad 和 Mac 上见下面的「iPad 和 Mac」。

添加到主屏幕的 App 里，最上面一行（首页的「编辑」「＋ 新建清单」、推进去那一页的返回和「⋯」）比在 Safari 标签页里低一点（约 24 点）：iOS 26 在状态栏下面画了一条渐变的模糊，贴着状态栏的字会被糊掉，所以让开这一截；吸在顶上的栏底色一直铺到最上面，滚上去的内容不会从那里透出来，从底部弹出的高面板顶上也不进那一截。横屏、Safari 标签页里不变。

### 清单

一开始有两张清单：

- **食材**：吃的、喝的、做饭用的。默认在 Whole Foods 买
- **想买**：衣服、书、日用品、工具……不一定马上买的东西也可以先放着

首页每张清单显示还要买几样，点一下进去。右上角「新建清单」：写个名字，选类型（**食材**：常见的东西自动分类；**一般**：多一个「以后再说」，能填链接和价格；类型建好以后不能改），选颜色和图标，选默认去哪家店买。

- 每张清单前面是一个带底色的圆角方块（和 iOS 提醒事项差不多），里面是和 App 其他图标同一套画法的线条图标；深色模式下底和图标都换成深色里看得清的颜色。食材是绿底菜篮，想买是琥珀底购物袋
- 面板最上面是图标的预览，选什么马上变。**颜色** 8 种（App 的绿、青、蓝、靛蓝、玫红、琥珀、陶土、石墨灰）；**图标** 30 个画好的（菜篮、蔬菜、购物袋、礼物、厨房、咖啡、酒水、药品、宝宝、宠物、衣服、鞋、家、家具、绿植、花园、工具、木工、装修、搬家、书、文具、电脑、手机、汽车、旅行、运动、节日、星星、爱心；读屏念名字）；也可以在「自定义」里写一个 emoji 或者一两个字（比如「木」「木工」），用选的颜色显示。没选的按类型用默认的样子
- 还不能用照片当清单的图标（照片只给食谱用，见 ROADMAP「以后 → 图片」）。以前选的 emoji 图标照样显示，放在默认颜色的方块上。另一台设备还没更新到新版时，画好的图标在那边显示成默认的 emoji；在那边改名字、换默认商店不会把图标弄坏（更新以后照样是选的那个）

- 左上角「编辑」：每张清单右边出现 ↑↓，排顺序
- 清单页右上角「⋯ → 编辑清单」：改名、换图标和颜色、换默认商店、归档、删除
- **归档**：不常用的先收起来，在首页最下面「已归档（N）」里，点开、点进去可以取消归档
- **删除**：只有自己建的清单能删，系统自带的两张只能归档。先问一句，删完 10 秒内可以撤销，过了也能在「设置 → 最近删除」里恢复；里面的东西跟着隐藏，清单恢复时一起回来

### 加东西

清单页最上面的输入框（往下滚也一直在顶上，返回和「⋯」也是），打字、回车就加好了，输入框留着可以接着加下一样。数量可以直接写在名字前后：

| 输入 | 加进去的是 |
|---|---|
| `牛奶` | 牛奶，1 |
| `鸡蛋 12`、`鸡蛋12个`、`鸡蛋 x12` | 鸡蛋，12（个） |
| `2 牛奶`、`两盒牛奶` | 牛奶，2（盒） |
| `面粉 1袋` | 面粉，1 袋 |
| `半斤肉`、`肉一斤半` | 肉，0.5 斤 / 1.5 斤 |
| `milk 2 gal`、`2 lb beef`、`2 bags of rice` | milk，2 gal / beef，2 lb / rice，2 bags |

- 认得常用的中英文单位（个、袋、盒、瓶、包、斤、磅、lb、oz、g、kg、mL、L、gal、dozen……，繁体、大小写都行）；全角数字、小数、`1/2` 也行。中文数字只在后面跟着单位时才算数量：「五花肉」「三明治」不会被拆开
- 「想买」这类一般清单：光写一个数字不算数量（`iPhone 15`、`100 Years of Solitude` 原样是名字），要写单位或者 x：`袜子 3双`、`电池 x4`、`socks 3 pairs`、`paper 10 sheets`（`pair`、`set`、`sheet` 写在名字前面时要带 of：`3 pairs of socks`；`10 sheet masks` 原样是名字）
- 连着字母的数字是名字的一部分（`维生素B12`、`V8`）；认不出来的整句当名字，加进去以后还能改
- 打字时下面列出以前买过的东西（名字开头就对上的在前，再按常买的、最近买的），旁边是常去的那家店，已经在这张清单上的标着「已在清单上」；点一下就加（输入里写了数量照样用上），Esc 或点别处收起来
- 已经在清单上的东西再加一次，会提示「已经在清单上了」、那一行闪一下，不会重复（因为食谱已经在清单上的也一样；想自己再多买一些，在编辑面板里改「自己加的」数量）。只有一种例外：这样东西只是因为食谱在清单上（自己没写过数量），这次又写了数量（`洋葱 2个`），就把它记成自己加的，提示「已经因为食谱在清单上了，另记了你自己要的 2 个」，这一行变成「3 个」或「2 个 + 200 g」。没写数量的照旧只提示：这样东西还是只为那道菜买的，以后在计划里删掉那道菜它会跟着拿掉；想不管菜都留着，写上数量（`洋葱 1`）
- 食材清单上打字时，联想的最后还有「用到它的食谱」（写「五花」联想出用到五花肉的红烧肉），点一下打开「加到清单」，默认加到这张清单（见下面「食谱」）
- 以前买过、已经清掉的东西再加，就是原来那一条：带上上次的分类、单位、备注（上次从食谱带来的用量不算了：那一轮已经买过）
- 商店默认是这样东西**常去的那家**（买的次数最多的；一样多取最近买的；归档的店不算），没买过的用清单的默认商店。这次想换一家买，改这一样就行，不会改掉以后的默认
- 常见的食材会自动分好类（牛奶 → 蛋奶，苹果 → 蔬果，冷冻草莓、冻虾仁 → 冷冻，冻顶乌龙茶、冻干草莓 → 零食饮料；繁体、英文也认得）；分错了改一次，以后都记得（改成「未分类」也记得）。写过的单位也记得（这次写了「面粉 1袋」，下次写「面粉」也是袋）

### 买到了

点这一行**左边的圆圈**才勾掉（点名字、数量这些别的地方是打开编辑面板，见下面「改一样东西」：推着车、滚着页面时不会一碰就勾掉）。圆圈能点的地方是左边整整一栏、和这一行一样高，不用对准那个小圆。勾掉时先在原地打勾、划线，再移到下面的「已买（N）」；在「已买」里再点一下圆圈就取消，也是先在原地去掉勾再放回去（从「以后再说」勾掉的，半小时内再点一下回到「以后再说」，不会变成要买；勾掉半小时以后再放回去是又要买了，上次从食谱带来的用量不算了）。挪之前再点一下就是不改了；连着点好几样时，等最后一下之后一起挪；刚挪到手指下面的那一行，紧接着的一下不算（连点两下不会改掉两样）。（系统设了「减少动态效果」时直接移过去。）用键盘、读屏：圆圈是一个复选框，读出来是「牛奶」、勾没勾，数量、商店、备注跟在后面；Enter / 空格勾掉或取消。勾掉一样以后，焦点落在顶替它位置的那一样的圆圈上，可以接着往下勾。

- 勾上半小时内又取消，算点错了（或者最后没买成），不算买过一次；隔久了再从「已买」点回来（又要买了），上次那次照样算在常去的商店里
- 「已买」可以折叠起来（每张清单各自记住）
- 「清除已买」（在「已买」旁边，也在「⋯」菜单里）把已买的都清掉，10 秒内可以撤销
- 「想买」这类一般清单还有「以后再说（N）」：先收着、不算在要买的里面。在编辑面板的「状态」里改（以后再说 ↔ 要买）

### 左右滑

每一行都能左右滑（像「邮件」「提醒事项」）：清单页（要买、以后再说、已买）、一家店的页面、搜索结果里都一样。

- **往右滑**，左边露出灰色的「编辑」：打开的就是点这一行的那个编辑面板
- **往左滑**，右边露出红色的「删除」：这一行收起来，和面板里的删除一样进「最近删除」，10 秒内可以「撤销」
- 每一行都一样（食材、一般清单，要买、以后再说、已买）。要移到「以后再说」或者移回要买，在编辑面板的「状态」里改
- 滑开只是露出按钮，要再点一下按钮才会编辑、删除；滑得再远、再快，松手也只是把按钮留在那儿（一行最多拉开按钮宽的一个半，越往外越拉不动），不会直接删除
- 同一时间只开一行；点别处、上下滚动、按 Esc 都会关上。点开着的那一行（圆圈也好、别处也好）只是关上，不会勾掉、也不会打开面板；开着一行时点别的行，也只是关上
- 上下滚动不会误滑（明显横着滑才算）；从屏幕最左边开始的不算（留给系统的返回手势）；页面放大着的时候横着拖是在看放大的页面，不滑
- Mac、iPad 的触控板两指左右扫也行（一样只露出按钮，扫得再猛也不会直接做；扫完还在滑的时候点这一行，和点开着的行一样只是关上，不会勾掉、不会打开面板）；鼠标拖不滑
- 用键盘、读屏：按钮关着时不在 Tab 顺序里、读屏也读不到（同样的事点这一行、在编辑面板里做）；开着时能 Tab 到，读出来是「编辑「牛奶」」「删除「牛奶」」，Enter / 空格就是点。删掉以后焦点落在下一行的圆圈上（删的是这一页最后一行就落在页面标题上）
- 系统设了「减少动态效果」时没有滑动的动画，点了按钮马上做
- 正滑着的时候别的设备同步来了改动，等滑完再刷新，手底下的行不会换掉

### 改一样东西

点这一行（圆圈以外的地方都行，右边的 › 是提示；或者往右滑点「编辑」）。用键盘、读屏时这一行是一个按钮「编辑「牛奶」」。面板里有：名字、数量（−/+，空着就是不写数量）、单位（下面有常用单位，点一下填进去）、商店（只改这一次）、分类、备注；清单（换一张就移过去，可以同时改名字；那张清单上已经有同名的，先问要不要合并成一条：这次改的数量、备注……都落在留下来的那一条上，这一条的链接、价格、备注也带过去，那一条已经有的不盖掉，两条的备注都有就接在后面）；删除（10 秒内可以撤销；改了还没点「保存」就点删除，先问要不要放弃修改）。已买的东西改了名字或商店，买的那一次跟着算到新的上面。一般清单的东西还有状态（要买 / 以后再说 / 已买）、商品链接和价格（链接是手动粘贴的，只收 http / https，「打开」在新标签页打开；现在不会自动读取网页）。点「保存」才存下来，有改动时关面板会先问一句「放弃没保存的修改？」（「继续编辑」接着改，「放弃」关掉；键盘上连按两下回车不会直接放弃）。

从食谱加进来的东西，面板里的数量叫「**自己加的**」（改的只是自己那一份），下面「**来自食谱**」列出每道菜的那一份（「红烧肉 1 个」「咖喱 200 g」），每份右边的 × 能拿掉这一份（点「保存」才算；拿掉以后什么都不剩的东西照样留在清单上，不要了就删除），再下面一句「清单上显示一共：3 个 + 200 g」跟着你改的数量变。

清单里的东西可以**按分类**或者**按商店**分组（每张清单在这台设备上各自记住），「未分类 / 未指定商店」排在最后，组里按名字排（简体界面按拼音）。不在清单默认商店买的东西标着店名（按商店分组时「要买」的组名就是店，只在「以后再说」「已买」里标）。一般清单里只剩「以后再说」时显示「还没有要买的东西」，不说「都买齐了」。每一行还显示数量、单位和备注的第一行。

**数量怎么显示**：一样东西要买的量 = 自己加的 + 各道菜的。单位一样的加在一起（「个」和「個」、「g」和「G」算一样），单位不一样的分开写：自己加了「洋葱 2个」，红烧肉要 1 个、咖喱要 200 g，这一行就是「洋葱 3 个 + 200 g」（自己的在前）。自己没写数量的只算菜的；都没写数量就不显示数量。清单页、一家店、搜索都这么显示；窄屏上只在「+」那儿折行。

### 按商店看

「商店」页列出每家店还要买几样，跨所有清单（只数「要买」的，不算「以后再说」和已买的；归档的清单上的东西也不算）。没有要买的店也列着，数字淡一点；没指定商店的（还有指定的商店删掉了的）在最后的「未指定」里。归档的店还有要买的东西时也列出来，标着「已归档」。右上角「管理商店」直接去「设置 → 商店」。

点进一家店，就是在这家要买的全部东西，按分类分组（和清单页一样），每样标着来自哪张清单（图标 + 名字）。点左边的圆圈勾掉（和清单页一样先在原地打勾再挪，这次算在这家店买的），点这一行别的地方是同一个编辑面板，左右滑也和清单页一样。下面「已买（N）」可以折起来（每家店在这台设备上各自记住），「清除已买」把在这家买到的都清掉，10 秒内可以撤销。右上角「⋯」和清单页一样：有已买的时候有「清除已买」，下面是「屏幕常亮」（见下面）。

**只看一张清单**：「商店」大标题下面、一家店「还要买 N 样」的右边，都有一个「所有清单 ▾」按钮（iPad 横放、Mac 上左右两栏时只在左边「商店」那一栏有一个，右边的店跟着变）。点开列出「所有清单」和首页上的每张清单（图标 + 名字 + 还要买几样；在一家店里点开时数的是在这家要买的，看得出哪张清单在这儿有东西；归档的清单不列），现在看的那张打勾。选一张以后：

- 「商店」页只列这张清单在那儿有东西的店，数的也只是这张清单上的；下面一句「另外 7 家店在「木工」里没有要买的」（要进别的店，换回「所有清单」）；一家都没有时说「「木工」里没有要买的东西」
- 一家店里只有这张清单上的东西（要买的、已买的都是），行上不再标来自哪张清单；「清除已买」也只清看得到的，别的清单在这家买到的不动
- 按钮换成那张清单的图标和名字（比如「木工 ▾」），底色变成绿色，一眼看得出这一页只看了一张；这家店在这张清单里没东西时说「这家店在「木工」里没有要买的东西」，并提醒可以在上面换回「所有清单」
- 「商店」页、每家店用的是同一个选择：换一家店还是这张。这台设备记住（关掉再打开还在），不同步：手机上只看「木工」、iPad 上看全部都可以
- 选的那张清单删掉或者归档了，就照「所有清单」显示，不另外提示（恢复、取消归档以后又只看它；这时在面板里点了「所有清单」就是真的换回所有清单了，以后恢复也不会再只看它）

一开始有这些商店：Whole Foods、Trader Joe's、Costco、Target、H Mart、99 Ranch、Amazon、The Home Depot。

- **设置 → 商店**：「新增商店」；每家右边一对 ↑↓ 排顺序（「商店」页和选择列表都按这个顺序；按完页面跟着滚，连着按挪的还是同一家）；点名字（右边有 ›）可以改名（不能和别的店同名）、归档、删除（改了名字还没点「保存」就点归档、删除，先问要不要放弃修改）。归档的不出现在选择里、不当默认，已经指定给它的东西照常显示，收在下面「已归档（N）」里，点开可以取消归档。删除先问一句（说清几样东西会变成「未指定」），10 秒内可以撤销；东西上记着的商店不动，删掉期间显示成「未指定」，商店恢复了就回来。自带的商店也能改名、删除，删掉的不会自己回来
- **设置 → 分类**：分三组——食材（只给食材清单）、一般（只给一般清单）、两边都用。「新增分类」时写名字、选用在哪种清单（建好以后不能改）；组内 ↑↓ 排顺序，就是清单里分组的顺序；点名字可以改名、删除。会出现在同一张清单上的分类不能同名（食材的和一般的可以同名）。自带分类的名字可以清空，就显示自带的名字（跟着界面语言）。删除先问一句，10 秒内可以撤销；分类里的东西归到「未分类」，分类恢复了就回来

### 屏幕常亮

在店里推着车、一只手拿着手机时，屏幕一暗就要解锁再找回来。清单页、商店页右上角「⋯」里有「屏幕常亮」开关：

- 打开以后，在清单页和商店页上屏幕不变暗（勾东西就在平时的页面上，点左边的圆圈，和平时一样）；去首页、食谱、日历、设置这些页面时放掉，回到清单页、商店页又自动打开。切到别的 App、锁屏时系统会收回，回来以后自动再要
- 开着的时候「⋯」左边有一个小小的「☀ 屏幕常亮中」，点一下就关掉
- 这台设备记住（关掉再打开 App 还开着），不同步：手机上开着、Mac 上关着都可以。默认关着（常亮费电）
- 设备或浏览器不支持时，「⋯」里那一行不是开关，写着这台设备做不到、可以把系统的「自动锁定」调长一点；被拒绝（比如开着低电量模式）时小标签换成灰的「没能常亮」，点一下它（或者页面上随便点一下）再试一次

以前有一个单独的「购物模式」（「开始购物」进去，大字、进度条），后来去掉了：点圆圈勾掉在平时的页面上就一样，不需要另一页；有用的只是屏幕常亮，留成了这个开关。以前的购物模式地址（历史记录、书签里的）打开的就是普通的清单页 / 商店页。

### 搜索

首页「清单」标题下面的搜索框（iPad、Mac 上侧栏也有「搜索」），一次搜所有清单里的东西：

- 边打边搜，名字和备注都搜；简体繁体、大小写、全角半角都算（搜「鸡蛋」也能找到「雞蛋」，搜「MILK」也能找到「oat milk」）。写几个词（空格隔开）就要每个词都有，可以一个在名字、一个在备注。输入法还在选字时先不搜
- 所有没删除的清单都算，已归档的也在（标着「已归档」，排在后面）；要买、以后再说（标出来）、已买（划线、淡一点）都列。删掉的清单里的东西、删掉的东西不算（它们在「最近删除」里）
- 结果按清单分组，组名是清单的图标和名字，点了进那张清单；每组里要买的在前，再以后再说、已买。名字里搜到的字用底色标出来；备注里搜到的，显示备注里有这个词的那一行，也标出来
- 点圆圈勾掉 / 放回去，点这一行别的地方打开编辑面板，左右滑（往右编辑、往左删除），都和清单页一样
- 搜索词记在地址里：点进一张清单再返回，还是刚才搜的。iPad、Mac 上搜索在右栏时，左栏的搜索入口和侧栏的「搜索」亮着，再点它们只是回到搜索框，搜的词不会清掉
- 不认拼音和错别字（搜「jidan」找不到「鸡蛋」）

### 食谱

底栏（侧栏）的「**食谱**」：

- **「食谱」页**：每道食谱一张卡片（有成品图的左边一张圆角小图；名字，下面「2 人份 · 8 样食材」，再下面是它的标签），按名字排（简体按拼音）；卡片右边的**购物车**直接打开「加到清单」（见下面），点卡片别的地方打开这道食谱。上面的搜索框边打边搜**名字、食材和标签**，简体繁体、大小写都算（搜「五花」找得到用到五花肉的红烧肉，卡片下面写「用到：五花肉」）。搜索框下面**按标签筛选**：「菜系」「风格」各一排（只列有食谱用到的，用得多的在前，标签多了横着滑），点一下选上、再点取消；一排里选几个是「任一」（川菜或湘菜），两排都选是「都要」（川菜里的下饭菜），「清除筛选」一下都取消。筛选下面右边是「**管理标签**」（见下面）。搜的词、选的标签在这次打开 App 期间记着（点进一道再返回还是刚才的）。右上角「新建食谱」（接了键盘时 ⌘N 也是），左上角「**食材替换**」（见下面；还没有食谱时没有）
- **管理标签**（「食谱」页筛选下面右边，有食谱就有）：一个面板，「菜系」「风格」两组，先列有食谱用着的标签和几道食谱用（「川菜 · 2 道食谱」），每个右边：
  - 「**改名**」：用到它的食谱一起改。改成这一组里已有的名字（哪种语言的预设名字也算），两个就合成一个，不会一道菜上有两个；和原来一样的说「和原来的一样」。预设改成别的名字以后变成自己写的标签，原来的预设不再出现在编辑页的选项里（在下面「没用到的预设」里能恢复）
  - 「**删除**」：先问「删除标签「下饭」？」，说清几道食谱上的会去掉、食谱本身不删（焦点先在「取消」）。预设删掉以后还是编辑页的选项，挪到下面「没用到的预设」
  - 改名、删除以后提示条上能撤销（10 秒内；提示条出现在面板上面，不用先关面板）
  - 下面「**没用到的预设**」：没有食谱用的预设标签，每个能「**不在选项里显示**」（编辑食谱时不再列出来，旁边标「不在选项里」）、「**恢复**」。这个设置开着同步时跟着同步，两台设备各藏了几个都留着
  - 改名、删除一次改完所有食谱，都能撤销（连藏起来的预设一起回来）；删掉的食谱（最近删除里）不跟着改
- **一道食谱**：最上面是成品图（有的话，大图），名字、几人份、标签、来源（链接在新标签页打开，别的照写）、大大的「**加到清单**」、食材（用量、备注；可选的、常备品标出来）、做法、备注；旁边的「**加到日历**」（选哪一天、哪一顿、几人份，见下面「日历」）；填了「每人份营养」的，食材下面写着「620 千卡 · 蛋白质 22 g · 碳水 18 g · 脂肪 50 g」，没填的写着按食材估算的「每人份约 520 千卡 · 蛋白质 25 g · 碳水 30 g · 脂肪 35 g（估算，2 样没算进去）」，点了看估算的明细（见下面「自动估算」）；右上角「编辑」，最下面「删除食谱」（先问一句，10 秒内能撤销，过了也能在「设置 → 最近删除」里恢复；已经加进清单的东西不受影响；计划里连着它的菜照样在，显示原来的名字）
- **编辑食谱**（新建也是这一页）：顶上「取消 · 新建食谱 · 保存」。名字、几人份（−/+，可以不写）、成品图（见下面）、食材一行一样：名字、数量、单位、备注（「切块」）、「可选」，右边 ↑↓ 排顺序、垃圾桶删掉这一行（写过东西的行删掉后 10 秒内能撤销，放回原来的位置）；下面「加一样」「粘贴食材」；再下面「**每人份营养**」（热量千卡、蛋白质 / 碳水 / 脂肪克，都可以不填；在日历里「吃了」这道菜时用它，见下面「饮食记录」；下面一块「按食材估算」：按这一页现在写的食材算的每人份（还没保存的也算，改了用量马上跟着变），「明细」打开估算的明细，「填进去」把估算的数填进上面四格再自己改、保存（没写几人份的算的是一整道菜，写上几人份才有「填进去」）。四格都空着时用估算的，填了以手动的为准）、标签、做法、来源、备注。
  - **食材的顺序**：默认按类别排——肉类海鲜 → 蔬果 → 蛋奶豆制品 → 粮油干货 → 调料酱料 → 其他（按常见食材的对照表分，和清单上的分类同一张；在清单上把一样东西改到别的分类，食谱里也按那个排），同一类里照原来的先后。粘贴进来的马上放进它那一类；「加一样」写的先接在最后，点「保存」时再放好（写着的时候不会跳走）。新建的食谱第一次保存时整张排好；已经存过的食谱（包括以前自己用 ↑↓ 排好的）原来的几行不会自己挪，新加的只放进它那一类的最后；新建时自己用 ↑↓ 排过也一样。食材上面的「**按类别重新排**」一下整张排好
  - **重复的食材**：加的这一样这道菜里已经有了（简体繁体、大小写一样也算），写好名字时这一行下面提醒「这道菜里已经有「生抽」了」：「**合并**」并进原来那一行（原来那一行的数量一直留着：单位一样数量相加，2 勺 + 1 勺 = 3 勺；这次没写数量只接上备注；单位不一样、原来那一行没写数量、加起来超过 9999 时，这次的写进那一行的备注；10 秒内能撤销），「**仍然加一行**」照样留着（腌料、调味各一份盐），这个名字不再提醒
  - **标签**：「菜系」（川菜、粤菜、湘菜、鲁菜、江浙菜、东北菜、台湾菜、家常中餐、日式、韩式、东南亚、西式、意式、墨西哥）和「风格」（家常、快手、下饭、减脂、素食、汤、凉菜、早餐、便当、甜品、烘焙、宴客）两组，点一下选上、再点取消，一道菜可以选几个；别的食谱用过的自己加的标签也列在里面；「+ 自己加」写一个新的（写的正好是某个预设的名字，哪种语言都算，就是那个预设）。预设的标签跟着界面语言显示（简体「意式」、繁体「義式」、英文「Italian」），以前存成哪种语言的字都认成同一个，不会一个意思两个标签；自己加的照写的字显示
  - **成品图**：「添加成品图」打开系统的选图（iPhone、iPad 上能拍照，也能从相册选；Safari 认得的格式都行，包括 HEIC；照片的方向按拍的时候摆正），压缩成长边 1600 像素的 JPEG（一张大约 200–500 KB），左边是预览；有图时「换一张」「删除图片」（删了 10 秒内能撤销）。和别的修改一样点「保存」才算（「正在处理图片…」时点了保存，等这张处理好了一起存；没处理成就留在这一页）；打不开的图片（文件坏了、格式不认识、太大了）在下面说一句，原来的图不动。这次编辑里加了又换掉、又取消的图不会留在这台设备上；以前存好的图换掉、删掉以后还留在这台设备上（开了同步的话仓库里也有，见下面「多设备同步」），在另一台设备上、从备份恢复的旧记录还可能用着它
  - **保存**：点「保存」才存（接了键盘时 ⌘S / ⌘回车也行；名字空着、数量写错了标在那一项下面）；新建的存好就是那道食谱的页面。名字框里按回车（iPhone 键盘的「下一项」）跳到几人份，几人份、来源里按回车收起键盘，都不会保存。还没写食材的食谱，「加到清单」不是绿色的主按钮
- 改了没保存时，「取消」、Esc、点底栏 / 侧栏 / 左栏换页、浏览器后退都会先问「放弃没保存的修改？」（「继续编辑」接着改）。没保存的修改也随手存在这台设备上：去小红书复制食材时 iPhone 把 App 关掉了也不丢，下次打开同一个编辑页接着改（上面写着，可以「放弃修改」）

- 按换行拆，一行里再按「、」「，」「；」「｜」拆，有汉字的行还按空格拆（单位、「适量」「约…」「各…」「可选」、切段拍碎这些、带分数跟着前面那一样，两个英文词中间不拆）；开头的「食材：」「主料」「【调料】」「Ingredients:」去掉；认得食谱常用的单位（g、克、斤、两、勺、汤匙、小勺、杯、碗、个、根、片、瓣、颗、朵、cup、tbsp、tsp、clove、floret……，台湾的公克、台斤、大匙、小匙、cc 也认；英文写成整个词的 pound、ounce、gram、kilogram、liter、fl oz 和带点的缩写 Tbsp.、tsp.、lb.、oz. 也认）；「适量」「少许」「若干」「一点」不算数量，写进备注
- 整篇笔记贴进来也行：表情先去掉（名字里不留，和清单上的东西对得上）；到「做法」「步骤」那一行就停（前后带表情也认得）；#话题、只有表情和标点的行扔掉；拆不出数量的整段当名字（不猜，比如 `½ cup milk`），加进去以后还能改

**加到清单**（一道食谱页面上的按钮、「食谱」页卡片右边的购物车，或者快速添加时联想出的食谱）：面板里

- **加到**哪张食材清单（默认「食材」；从清单页的联想打开时默认是那张）
- **几人份**：−/+，用量按比例算（食谱 2 人份、选 3 人份，500 g 就是 750 g；没写数量的「盐 适量」不变；算出来超过 9999 也照算）。食谱没写人数时不能换算，照原样。框里写的不对（空着、0、超过 99）时下面标出来，「加到清单」点不了
- **每样食材一个勾**：**常备品**（盐、油、生抽……家里一般都有的）和「可选」的默认不勾；清单上已经有的写着「清单上已有 2 个」；**这道菜已经加过的**写着「这道菜已经加过 500 g」，也默认不勾（再打开面板看看加了什么，不会一下就加成两份），下面说一句「再勾上就是再加一份」。每行右边「常备品」点一下就标上（按名字记，以后所有食谱都认；标上顺手取消勾，取消就勾回来；同名的几行一起）
- 「加到清单（5 样）」：清单上已经有、还没买的，把这道菜的用量记在它上面（自己加的数量不动）；没有的、已经买过或清掉的，重新成为一样要买的（上一轮买的不算了）。分类、商店照平常新加时的规矩。10 秒内能撤销（这次标的常备品一起撤销）。同一道菜再加一次（自己勾上）就是两份

**食材替换**（「食谱」页左上角）：搜一样食材（食谱里用到的，后面写着几道食谱用到）→ 点它，列出用到它的食谱和那几行（名字一样的，「生抽王」不算「生抽」）→ 在「换成」里写新名字 →「替换」：所有食谱里这几行一起改名，数量、单位、备注不变；它是常备品的话，新名字也标成常备品；有的食谱里本来就有新名字那一样时，先说一句「「红烧肉」里已经有「酱油」，换了以后会有两行」（照样能换）。「换成」在食谱列表上面，用到它的食谱再多也不用往下翻。搜的时候名字开头就是这个字的在前（回车选第一个）。10 秒内能撤销（一次全回来）。清单上已经有的东西不改。新名字空着、和原来一样时不换

### 日历

底栏（侧栏）的「**日历**」（以前叫「计划」，旧的链接照样打开）：一周吃什么，按这几天的菜一起生成购物清单；每天下面还有实际「**吃了什么**」（见下面「饮食记录」）。

- **一周**（默认）：周一到周日七天，上面 ‹ › 换一周，「今天」回到这一周、滚到今天那一张。点「日历」进来时直接滚到今天（周一就在最上面；点进一道菜的食谱再返回，还在原来的位置）。每天一张卡片，写着星期几和日期（今天标出来），下面按**早饭、午饭、晚饭、加餐**列出这一天的菜：连着食谱的写食谱名（食谱改了名字跟着变，删掉了照样显示原来的名字），没连的写你写的那句（「出去吃」「公司食堂」）；下面一行是几人份和备注；连着的食谱有成品图时右边一张小图，再右边一个「**吃了**」。没安排的那天写着「还没安排」。卡片下半是这一天「吃了什么」和合计；最上面写着这一周平均每天多少千卡（只算记了的日子）
- **一个月**：右上角「按周 / 按月」换过去（这台设备记住）。月历周一开头，每天有几道菜就几个点（最多 3 个），点的下面一行小字是那天吃了多少千卡（记了的日子）（超过目标的是琥珀色），今天是绿底的数字；点一天，下面列出那一天（和一周里的卡片一样，也能加、能记）。前后补上的别的月的日子，点了就翻到那个月
- 看到哪一周、选的哪一天在这次打开期间记着：点进一道食谱再返回，还是刚才那一周
- **加一道菜**：每天右边的「+」（接了键盘时 ⌘N 也行）。上面搜食谱（名字和食材都搜，简体繁体都行），点一道就选上（选错了点「换一道」；回车选第一道，名字里有搜的字的排在只是食材里有的前面）；不选食谱就记下框里写的那句（打的正好是一道食谱的名字，直接按「添加」也会连上那道食谱）。再选**哪一天**、**哪一顿**（默认晚饭）、**几人份**（连着食谱才有，默认是食谱写的人数，生成购物清单时用量按它换算；食谱没写人数就照原样）、备注。「添加」以后提示加到了哪天，10 秒内能撤销
- 食谱页的「**加到日历**」是同一个面板：食谱已经选好，默认今天的晚饭，改成哪一天、哪一顿就行
- **点一道菜**：「打开食谱」、改几人份、改日子或者哪一顿（就是挪过去；挪到这一页看不到的日子，页面跟着翻过去、滚到那一天）、换一道、备注，「保存」才算；「删除这道菜」不用确认，10 秒内能撤销
- **生成购物清单**（右上角）：
  - **从 · 到**：一开始是正在看的这一周（看一个月时是选中那天的那一周），也能自己选起止的日子（结束不能早于开始）
  - **加到**哪张食材清单（默认「食材」）
  - 这几天所有连着食谱的菜的食材**合在一起**：同名同单位的相加（红烧肉要洋葱 1 个、咖喱要 2 个 → 「洋葱 3 个」），单位不一样的分开两行；每行写着来自哪几道菜（「燕麦粥（周一、周五）」；选的日子超过一周时写日期「红烧肉（11月23日、11月30日）」），按各道菜的人数换算。没连食谱的菜（「出去吃」）上面说一声，不算在里面
  - 每行一个勾：**常备品**和「可选」的默认不勾（每行右边也能标 / 取消常备品，和「加到清单」一样）；清单上已经有的写着「清单上已有 1 盒」；**已经为这几道菜买过的**（勾掉了、清掉了，后来因为别的菜、快速添加又加回清单的也算）写着「已经买过」，默认不勾——买完了再生成一次，不会把买过的又放回清单上（真要再买一次就勾上）
  - 「加到清单（N 样）」：**每道菜的用量分开记**（清单上那一样的编辑面板里「来自食谱」一道一份），所以以后删掉其中一道只减它那一份。分类、商店照平常新加的规矩；10 秒内能撤销
  - **同一段日子再生成一次不会加成两份**：已经加过的那几行照样勾着，写着「已经加过 3 个」（清单上还有自己加的、别的菜的，再写「清单上一共 …」），确认就是换成这次的用量（改过人数的按新的）；勾着的都是加过的时按钮写「更新清单（N 样）」，什么也没变的话确认后说一句「清单上已经是这些了」；去掉勾就是这几道菜不要它了，从清单上拿掉（全去掉勾也行，按钮变成「拿掉（N 样）」）。同名不同单位的分开算：上次只勾了「牛奶 ml」，「牛奶 杯」不算加过。换一张清单生成，是从原来那张挪过去，不是两边各一份
  - **清单上改过名的照样认得**：把「五花肉」改成「有机五花肉」（换了商店、写了备注）以后再生成，那一行写着「清单上叫「有机五花肉」」，确认是就地换它上面的用量（别的菜要的五花肉也算在它上面），不会删掉它、也不会另加一条「五花肉」。食谱里改了食材的名字（洋葱 → 红洋葱）不一样：那是食谱变了，再生成是拿掉洋葱、加上红洋葱
  - 生成到一张清单以后又删掉了那张清单：那几样跟着藏起来，不算「已经加过」，再生成到别的清单就是新加的（藏着的那几份拿掉，以后恢复那张清单不会算两遍）
  - 用量按人数换算以后不先四舍五入：3 人份的炒饭（洋葱 1 个）做三天、每天 1 人份，加起来是 1 个，不是 0.99 个
- **清单跟着计划变**（只动还没买的；已经买了、清掉的不动，自己加的数量也不动）：
  - **删掉一道菜**：清单上这道菜的那一份拿掉；只为它加的东西（没有自己加的数量、也没有别的菜要）从清单上拿掉，提示条上说拿掉了几样，撤销时一起回来
  - **改几人份**：已经加进清单还没买的那几样按新的人数重算（只是已经在清单上的那几样，当时没勾的不会冒出来；清单上改了名的照样认得、就地重算；食谱里后来删掉的那一样照原样留着，不会被拿掉），提示条上能撤销（算出来和原来一样就不提示）
  - **换一道菜**（换成另一道食谱，或者改成只写一句）：旧的那一份拿掉，新食谱的食材加到同一张清单（常备品、可选的、已经为这道菜买过的不加——除非它现在就在清单上要买：自己勾上的生抽、香菜，新的菜也用就留着，换成新菜的用量）；这道菜还没生成过购物清单的话清单不动
  - **挪到别的日子**：还是同一道菜，清单不动
  - 两道菜都要的东西（洋葱），删掉一道只减它那一份；自己也加过的（快速添加时写了「洋葱 2」）照样留着
  - 删掉的菜的那一份从别的路回到了清单上（勾掉以后删了菜、半小时内又取消勾选；另一台设备还不知道删了又生成了一次）：下次「生成购物清单」时（哪几天都行）顺手拿掉
  - 编辑面板「来自食谱」里计划的菜写着哪一天（「燕麦粥 · 11月23日 周一」）：同一道菜排了两天是两份，拿掉的是哪天的分得清

### 饮食记录

日历里每一天下半是「**吃了什么**」（像 MyFitnessPal、Lose It! 那样记卡路里，只是简单很多）：

- 按**早饭、午饭、晚饭、加餐**列出这一天记的，每样写名字、几份（不是 1 份才写）、蛋白质 / 碳水 / 脂肪（短写「蛋白 14 · 碳水 48 · 脂肪 9 g」，英文「P 14 · C 48 · F 9 g」，一条两行放得下；读屏念全的），右边是热量（千卡）；没填热量的写「没填热量」。点一条就能改；按估算记下的，打开了写着「记的时候是按食材估算的（约），改了就算自己填的」
- 下面是**合计**：设了目标（设置 → 饮食目标）的写「1630 / 1800 千卡」和「还差 170」或「超了 130」（超了是琥珀色），下面一条细细的进度条；蛋白质、碳水、脂肪各一格「78 / 90 g」也各有一条（没数也没目标的不画）。有没填热量的写一句「1 样没填热量，没算进去」
- **记一样吃的**：「吃了什么」右边的「+ 记一样吃的」，或者计划里那道菜右边的「**吃了**」：
  - 「吃了」：那道食谱已经选好、那一天那一顿、**1 份**（计划写的是做几人份，吃的是其中一份；两个人分着吃、第二天吃剩的，可以再记一次）。食谱填了「每人份营养」就直接带上，点「添加」就好；没填的带上按食材估算的（说一句「下面是按食材估算的（约），可以改」，有没算进去的写上是哪几样：「1 样没算进去：鸡腿」；食谱没写几人份的说「下面是一整道菜」，只吃了一部分就改份数），直接「添加」就记成估算的（日历上写「约」），食谱不变（它本来就用估算的）；改了框里的数就是自己填的，「也记到食谱里」（默认勾着）勾着的话写进食谱的每人份营养，下次直接带上。估算也算不出来的（食材都没写用量、都认不出，或者算进去的只有水、盐这些没热量的）空着，这次自己填只写了一句的（「公司食堂」）记过一次以后，下次「吃了」也带上上次填的数
  - 上面的框一打开列着「**常吃的**」（记得多、最近记的在前），打字时联想常吃的和食谱（简体繁体都行；食谱下面写着每人份，估算的写「约」，有没算进去的也写着）；点常吃的，名字和每份营养填好，光标跳到「添加」上（手机上键盘收起来，直接点「添加」）；点食谱就选上这道（「换一个」重选）；都不点就是自己写的——比如「拿铁」「公司食堂的午饭」，写的这一样记进常吃的，下次一打字就有。写的正好是常吃的名字（没点它），营养也自动填上记住的；自己没填的数不会把记住的冲掉
  - 再选**哪一天**、**哪一顿**（默认现在这一顿：早上是早饭、中午是午饭、下午三四点和晚上九点以后是加餐）、**几份**（−/+ 每次半份）、**每份营养**（热量、蛋白质、碳水、脂肪，都可以不填）、备注；不是 1 份时下面写合计。写错的（不是数、负数、热量超过 9999、营养素超过 999 克）标在那一格下面
  - 「添加」以后提示记到了哪天，10 秒内能撤销
- **改一条**：框里是每份的数；只改份数，合计按比例跟着变（2 份 1300 千卡改成 1 份是 650）；只改了一样（比如脂肪），别的合计不变；改日子、哪一顿就是挪过去。「删除这一条」不用确认，10 秒内能撤销。自己写的那样改了名字或数，常吃的也跟着改
- **记下来的数不会自己变**：记的那一刻把营养抄下来，以后改了食谱的每人份营养、改了常吃的，过去记的照旧（要改就点那一条改）
- **一周的平均**：一周视图最上面「这一周平均每天 1409 千卡（记了 4 天）· 目标 1800 千卡」，只算记了的日子（没记的那天不当成吃了 0），**不算今天**（今天还没吃完：早上只记了早饭也算进去的话，平均一整天都偏低）——今天记了东西时写「（记了 4 天，不算今天）」，这一周只有今天记了的不写。**一个月**里每天写着吃了多少千卡
- **饮食目标**（设置 → 饮食）：每天热量（千卡）、蛋白质、碳水、脂肪（克），都可以不填；一格写完（离开输入框、按回车）就存，写 0 或清空就是不设。目标同步到别的设备（每一样各自同步：一台设了热量、另一台还没同步时设了蛋白质，两样都留着）
- **数都是自己填的或者估算的**：手动填的（包装上的营养成分表、别的 App 查到的）为准；食谱没填的按食材用量估算（见下面「自动估算」），只是**估算**，界面上写「约」（合计里有估算的也写「约」），每个数都能改；只是给自己看的参考，要吃多少因人而异

### 自动估算

食谱没填「每人份营养」时，App 按食材的用量和内置的营养表（见下面「营养数据」）估算每人份的热量和营养素：每样食材换成克（克、斤两、台斤直接换；毫升、勺、杯按这一样的密度；个、根、片、瓣按表里一个的重量：一个鸡蛋 50 g、一瓣蒜 3 g），乘上每 100 g 的营养，加起来再除以几人份（食谱没写几人份的，一整道当一份，标题写「营养（整道菜）」、写「整道菜约 …」）。

- **食谱页**：食材下面「每人份营养」写着「每人份约 520 千卡 · 蛋白质 25 g · 碳水 30 g · 脂肪 35 g（估算，2 样没算进去）」；一样也算不进去的写「还估算不出来：…」，算进去的只有水、盐这些没热量的也是（不写成「约 0 千卡」）；某一样营养素也一样：鱼豆腐自己只填了热量、别的只有水和盐，蛋白质、碳水、脂肪是不知道（不写、记饮食时算没填），不是 0 g。手动填了每人份营养的照写手动的，不显示估算
- **估算的明细**（点那一行）：每人份和几人份一共多少；「**没算进去的**」每样写着原因——没写用量（适量、少许：在「编辑」里写上就能算；从编辑页打开的写「写上用量就能算」）、营养表里没有这一样、不知道一个有多重（「鸡腿 2 个」：USDA 的一个鸡腿连着背，差太远不用）、认不出单位（「牛奶 1 盒」）；「**算进去的**」每样写着用量、换成多少克（写的就是克的不再写一遍）、按表里的哪一样（写的是对上的那个名字：写「马铃薯」就是「马铃薯」，繁体界面上对不上的用台湾的说法）、约多少千卡（不知道密度、按 1 毫升 1 克算的也写着）；「**可选的，没算**」；最下面是准确度的说明和数据来源
- **指定成…**：认不出的（鱼豆腐、小番茄）、认错了的，搜营养表（中文、英文、简体繁体都行；一开始写着这一样的名字，「鱼豆腐」找得到「豆腐」；每样下面写着每 100 g 的四样），点一样就按它算（键盘上的「搜索」只收起键盘，不会替你选第一个）
- **自己填**：每 100 g 的热量、蛋白质、碳水、脂肪（包装上的营养成分表一般就是每 100 g 的；表里有这一样的，格子里淡淡写着表里的数，哪一格不填就那一样照它算：只抄了热量，蛋白质、脂肪还是表里的），单位不是克、毫升的还能填「一个有多重」（「鸡腿 2 个」填一个 150 g 就能算）。表里没有的至少要填热量，没填的那几样不算进合计（明细里那一行写着）；写错的（不是数、每 100 g 超过 900 千卡或某一样超过 100 g、一个超过 10 kg）标在那一格下面。自己说过的还能「**用回自动认的**」（以后再指定、再填从空的开始；别的设备同步过来，撤掉的也不会回来）
- 指定的、自己填的**所有食谱都认**（记在食材的名字上，「鱼豆腐（切块）」「鱼豆腐, 切块」和「鱼豆腐」是同一样，简体繁体也是），同步到别的设备，10 秒内能撤销。名字正好是「常吃的」里记饮食时写过的（每份的营养），存了以后它变成食材的营养，记饮食时不再联想它（面板上说一句；过去记的不变）
- **用手动的**：明细最下面，把估算的每人份抄成手动的「每人份营养」（10 秒内能撤销），再到「编辑」里改；抄了以后改了食材、指定了食材不再跟着变。没写几人份的（算的是一整道菜）要先写上几人份；估算不出来的、一份超过 9999 千卡或某一样超过 999 g 的（多半是用量写错了）不给抄，记饮食时也不填
- **记饮食**：「吃了」、从食谱选的，食谱没填每人份营养就用估算的（见上面「饮食记录」），记的时候抄下来：以后改了食材、指定了食材，过去记的不变
- **只是大概**：按 USDA 的营养表和食材的**生重**算的——炸、煎时吸进去的油、炖的时候化掉的油、蒸发和损耗都没算，同一样东西的品种、部位、牌子也差得不少，和实际吃的差个 **20–30%** 很正常。油、糖写了用量才算得进去（「油 适量」不算，明细里列着）；肉、油这些热量大的写准一点，估算就准不少

## 多设备同步

开启后，在任何一台设备上加的、勾的、改的，其它设备打开时都会自动拿到。数据存在你自己的 GitHub 私有仓库 `pick-nest-data` 里（一个文件 `picknest.json`，食谱的成品图在 `images/` 里），不经过任何别的服务器；每次同步是一次提交，仓库的历史记录也是一份备份。

同步状态有一个小标签：已同步（绿点，后面是时间）、待同步 / 同步中 / 离线 / 稍后重试（灰点）、令牌快到期（黄点）、同步出错（红字）、未开同步（空心）。iPhone 上在首页「清单」标题右边；iPad、Mac 上在侧栏左下角「设置」下面（首页标题旁边就不重复了）；「设置 → 多设备同步」那一行也有。点它去「设置 → 多设备同步」。

### 第一次设置（只需要做一次）

1. 新建一个**私有**仓库 `pick-nest-data`（App 会先确认仓库是私有的，不是私有的不会上传任何东西）：
   - 用 GitHub Desktop：**File → New Repository**，Name 填 `pick-nest-data`，建好后点 **Publish repository**，勾上 **Keep this code private**，再点 Publish
   - 或者在 github.com 右上角 **+ → New repository**，Repository name 填 `pick-nest-data`，选 **Private**
2. 新建一个 Fine-grained 令牌：打开 <https://github.com/settings/personal-access-tokens/new>
   （也就是 GitHub 右上角的**头像 → Settings** → 左侧栏最下面的 **Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**。注意是账号的 Settings，不是仓库里的 Settings）
   - **Token name** 随便起一个认得出来的，比如 `PickNest sync`
   - **Expiration** 选一个有效期（比如 90 天或更长），记下到期日
   - **Repository access** 选 **Only select repositories**，只选 `pick-nest-data`
   - **Permissions → Repository permissions → Contents** 设成 **Read and write**（Metadata 保持 Read-only，别的都不用加；新版页面可能要先点 **Add permissions**）
   - 点 **Generate token**，马上复制生成的令牌（`github_pat_` 开头，离开页面就看不到了）。App 只收 `github_pat_` 开头的：经典令牌（`ghp_` 开头，或者以前那种没有前缀的一长串）不收，它能动你整个 GitHub 账号
3. 打开 App「设置 → 多设备同步」，「第一次设置」里：仓库填 `你的用户名/pick-nest-data`（框里灰色的 `chizhangrit/pick-nest-data` 只是例子，要自己填），粘贴令牌，「令牌到期日」填上第 2 步记下的日子（可以不填，填了会提前两周提醒；连好以后也能在「设置 → 多设备同步」补上，选好日期点「保存到期日」），点「连接」。App 会先检查仓库在不在、令牌能不能看到它、是不是私有的，再马上同步一次；不行的话按钮上面会说原因（仓库名写错了、令牌没选这个仓库、仓库是公开的、令牌过期了……）

### 其它设备

在已经连好的设备上「设置 → 多设备同步」点「复制同步码」（`picknest-sync:` 开头），用隔空投送或者通用剪贴板送到另一台设备，在那台设备的「设置 → 多设备同步」最上面「已经在别的设备上开了同步」粘贴进去：仓库和令牌（那台设备填过到期日的话，到期日也在同步码里）自动填好，点「连接」。iPhone、iPad、Mac 都用**同一个同步码**。同步码里就是令牌原文，只发给自己的设备，不要发到群里。

### 怎么同步

- 改动后两秒左右自动上传（连着改几下只传一次）；切到别的 App、锁屏的时候，有没传的改动马上传（正在检查别的设备的改动也先停下来，先传这一次）
- 打开 App、切回 App（离上次超过 5 秒）、联网时，以及开着的时候每分钟一次，会检查别的设备有没有改过
- 每次先拿别的设备的改动、合并好，再把本机有、云端没有的传上去；没有新改动就不提交
- 几台设备都改过的话逐条合并：每一条（一样东西、一张清单、一家店……）取较新的那次修改。同一样东西在两台设备上同时改，以后改的为准（不是逐个字段合并）。删除也是一样：别的设备上删掉的（包括删掉的自带商店、分类），同步以后这台也删掉，不会自己回来
- **一个人在店里勾，另一个在家里排菜**：店里那台勾掉了洋葱，家里这台还没同步到，又加了一道菜、重新生成购物清单（洋葱整条改写了）——同步以后洋葱还是买过的，只剩新加的那道菜要的那一份在清单上（再生成也认得前面几道是买过的）。只是改了备注之类的，同步后还是已买、备注是新写的。在见过「已买」以后自己取消勾选、撤销的，照样是要买
- 两台设备还没同步过清单就各自生成了不同的几天：同步后两边的用量都算上（洋葱 1 个 + 2 个 = 3 个）
- 新设备还没连上同步（或者 Safari 清掉了这台的数据）就先加了以前加过的东西：连上以后是同一条，原来的备注、链接、价格、商店、记住的单位和常去的商店都还在（这次加的数量、「要买」照样算）。两台设备离线时各加一次同名的，同步后也还是一条
- 两台设备同时上传撞在一起时，后到的那台会重新拿一次、合并、再传（最多试 4 次，不行就下一轮再来）
- 没网时照常用，改动先存在本机，联网后自动补传。GitHub 说请求太多时，标签显示「稍后重试」，到了它说的时间再自动同步
- 「设置 → 多设备同步」能看到仓库、上次同步时间、有没有还没上传的修改、还有几张成品图没上传 / 在下载、出错的原因（写成一句话），也可以「立即同步」
- 本机数据坏了、进了恢复页时完全不同步，坏了的数据不会传上去；修好以后接着同步
- **食谱的成品图**：存在每台设备自己的存储里，开了同步时传到仓库的 `images/` 文件夹（`images/<一长串>.jpg`，按图片内容命名；同一张图只传一次）。每次先传图、再传 `picknest.json`，别的设备拿到食谱时图已经在仓库里了；别的设备上在后台一张一张下载（最近改过的食谱的先下），打开一道食谱、编辑它时还没下载的那张马上下载（上面写「正在下载图片…」）；「食谱」页、计划里的小图不单独下载，等后台下好了自己出现。还没传上来（那台设备没联网）、没开同步的设备上写「这台设备上没有这张图」（矮矮的一条），等传上来以后会自己补上（刚问过仓库里还没有的，5 分钟内不再问）。这台设备的存储空间满了、存不下图时：打开的那道照样看得到（这次打开期间），别的不再下载（不白费流量），「设置 → 多设备同步」里说一句，空出地方以后自己接着下。图片没传上 / 没下载成不算同步出错，文字照常同步，「设置 → 多设备同步」里写着还有几张、为什么没成，下一次再试。**换掉、删掉的图在仓库里和提交历史里一直都在**（只增不改；仓库是私有的，但要彻底删得自己在 GitHub 上清历史）
- 仓库里的 `picknest.json` 就是全部数据（清单、东西、食谱、计划、吃了什么、常吃的、饮食目标、商店、分类、买过的东西的习惯和常备品；成品图在旁边的 `images/` 里），文件超过 1 MB 也照样能同步。被手动改坏了的话，App 会报错、不会覆盖它；在 GitHub 上把它改回去（或者删掉，下一次同步会重新写一份）就好

### 换令牌、停止同步、安全

- 令牌快到期（两周以内）时，「设置 → 多设备同步」和同步状态的小标签（iPhone 上在首页标题旁边，iPad、Mac 上在侧栏「设置」下面）会提醒（要填了到期日；用带着到期日的同步码连上的设备也会提醒）。在 GitHub 新建一个令牌（权限和原来一样），在一台设备的「设置 → 多设备同步」点「换令牌」粘贴进去、点「保存」，不用停止同步；再点「复制同步码」，在其它每台设备上也点「换令牌」，粘贴这个新的同步码。令牌已经过期或者被删掉了也一样；在换好之前，各台设备照常能用，改动先存在本机，换好后自动补传
- 令牌只保存在这台设备上（本机设置里），不会进备份文件，也不会上传到仓库
- 令牌只能访问 `pick-nest-data` 这一个仓库的内容
- 不想用了：在每台设备上点「停止同步」（先问一句；本机的清单都留着，仓库也不动），再到 GitHub 上删掉这个令牌。以后要再开：在 GitHub 新建一个令牌（「第一次设置」第 2 步），照第 3 步重新连接，再把新的同步码粘贴到其它设备上；只停了一部分设备的话，在还开着的设备上「复制同步码」就行

## 备份与恢复

「设置 → 备份与恢复」：

- **导出备份**：一个 JSON 文件 `picknest-backup-年月日.json`，里面是所有清单、东西、食谱、计划、吃了什么、常吃的、饮食目标、商店、分类和买过的东西的习惯（「最近删除」里的也在）。没有同步令牌，也没有这台设备的设置（语言、外观、各清单的显示方式、按商店看时只看哪张清单、日历看一周还是一个月）。**备份里没有食谱的成品图**：图片只存在这台设备上（开了同步时仓库的 `images/` 里还有一份），备份只记着哪道食谱有图；在新设备上从备份恢复后，开了同步的话图会从仓库下载，没开就写「这台设备上没有这张图」。页面上写着这台设备上存了几张成品图、一共多大。能用系统分享的浏览器上（iPhone、iPad，还有 Mac 上的 Safari）还有「分享备份…」，可以存到「文件」或者隔空投送到别的设备。下面写着「上次备份：今天 / 3 天前 / 还没备份过」，还没备份过或者 30 天以上没备份时是琥珀色（设置首页「数据」下面也写着）
- **从备份恢复…**：选一个备份文件，先告诉你里面有几张清单、几样东西（有食谱、计划、吃了什么的话还有几道、几条）、是什么时候的，点「恢复」后**合并**：每一条取较新的，这台设备上有、备份里没有的不会被删掉；完了说改了几条（备份里没有更新的就什么也不改）。开着同步时，合并的结果马上同步到别的设备。不是 PickNest 的文件、读不出来的文件、新版 App 做的备份都会直接说清楚，不会动现有的数据。同步仓库里的 `picknest.json`、出错时下载的原始数据也能拿来恢复
- **恢复前的原始数据**：在恢复页修过本机数据以后才有，下载修之前存下的原件（排查问题用，里面没有同步令牌）

### 本机数据损坏时

本机存的数据读不出来时，App 会盖上一个恢复页，暂停修改和同步，不会把坏了的数据当成空白的清单继续保存。可以：

- 「下载原始数据」：先留一份原件（里面没有同步令牌）
- 「重新读取」：存储临时出问题（比如权限）时再读一次
- 「从备份恢复」：选一个备份文件
- 「从云端恢复」（开过同步才有）：只读地取仓库里现在的那一份。令牌过期了取不到时会说一声：先「保留读得出来的部分」，再去「设置 → 多设备同步」换令牌，换好以后云端的那一份照样会合并进来
- 「保留读得出来的部分，继续使用」

后三个都会先确认，把选的数据和读得出来的部分逐条合并；替换之前先把原件存档（之后在「设置 → 备份与恢复」里还能下载；只留最近一次的，旧的下载不到，留着只占空间），存档或写入失败时不会清掉原件。修好以后马上同步一次，合并的结果会传上去。

## 最近删除

删掉的清单、东西、食谱、商店、分类都在「设置 → 最近删除」里，按种类分组，新删的在前，每一项旁边有「恢复」。删除一律只是做个标记，内容一直留着（也照样同步），所以过多久都能恢复；恢复也会同步到别的设备。

- 删掉的清单里的东西不单列：恢复清单时一起回来（那一行写着有几样）。在清单删掉之前就分开删掉的东西，等清单恢复了再单独恢复
- 「清除已买」清掉的东西也在这里（标着「已买」），恢复后回到那张清单的「已买」里；以后再加同名的东西，也会直接恢复那一条
- 清单上已经有同名的东西、已经有同名的商店或者会一起出现的同名分类时不能恢复（会说一声，东西会说是哪张清单上的），先把现在那个改个名字
- 东西很多时先列 50 样，下面「再显示」
- 食谱下面写着有几样食材；同名的食谱可以有好几道，随时能恢复。食谱恢复了，以前从它加进清单的东西不会跟着变（它们是清单上的东西）
- 计划里删掉的菜、吃了什么里删掉的一条不在这里（太多太碎）：删的时候提示条上 10 秒内能「撤销」

## 营养数据

App 里带着一份常见食材的营养表（`src/data/nutrition.js`，四百多样），按食谱的食材用量估算每人份营养（见上面「自动估算」）用的就是它。

- **来源**：U.S. Department of Agriculture, Agricultural Research Service. FoodData Central (SR Legacy, 2018)。美国农业部的公开数据，公共领域（CC0），可以随意使用；PickNest 只是从里面挑了一部分、配上中文名
- **有什么**：每样食材每 100 g（可食部分，多是生重）的热量（千卡）、蛋白质、碳水、脂肪（克）；中文名和常见叫法（简体写的，繁体靠简繁互通也认；台湾常见的另外收了一些：高麗菜、馬鈴薯、鮭魚、蕃茄、柳丁、無鹽奶油、太白粉），英文名（明细里繁体界面上表里的名字按字转成繁体显示、英文界面用英文名，只是写法：「土豆」还是土豆）；汤、面团里的水（清水、开水、温水……）也收了，0 千卡，不会列成「没算进去」；有 USDA 数据的写着常见单位的克数（一个鸡蛋 50 g、一瓣蒜 3 g、一勺生抽 16 g、一杯米饭 158 g、一块西瓜 286 g……）。重量和体积单位也认台湾、美国的写法：公克、cc、公升、台斤（600 g；只写「斤」按 500 g）、大匙、小匙、qt、pint、gal、pound、ounce、fl oz、liter
- **中式的东西 USDA 里不全**：没有完全对应的，用最接近的一样，表里写着用了什么——老抽按 tamari（更浓的酱油）、香醋 / 陈醋按意大利黑醋、料酒 / 黄酒按清酒、豆瓣酱 / 黄豆酱按味噌、甜面酱按海鲜酱、腐竹按冻豆腐干（koyadofu）、腊肉按猪五花、黄鳝按鳕鱼（一样瘦）、山药按夏威夷山药、小米辣按 serrano、带鱼按西班牙鲭鱼、馒头按白面的皮塔饼……；说法有歧义、营养差得多的不收（「奶油」在大陆多是淡奶油、在台湾是黄油；「椰汁」可能是椰子水也可能是椰浆）
- **宁可认不出，也不认错**：和表里那一样差得多的认不出，到时候自己指定、自己填——小的品种（小番茄、小土豆、小黄瓜：一个的重量差好几倍）、干的腌的熏的（干豆腐、dried apricots、smoked salmon：每 100 g 差好几倍）、泡发水发的干货（水发腐竹、泡发香菇：每 100 g 是干的几分之一）、看着像其实是别的东西的（鱼豆腐、杏仁豆腐、水淀粉、贝贝南瓜）、英文里前面是别的食物的（tuna steak 不是牛排、turkey bacon 不是猪肉培根）。USDA 的「一个」和中文说的差太远的也不用（一个鸡腿、一块牛排、一个辣椒），换算不了的到时候列出来；「一块西瓜」是切下来的一块，不会算成一整个。木耳、黑木耳、云耳按泡发的（鲜的，每 100 g 25 千卡）算：菜谱里写的多是泡发以后的重量；写了「干木耳」的才按干的算（284 千卡），银耳按干的
- **都是估算**：同一样东西的品种、部位、做法、牌子差得不少，算出来的只是大概，界面上一律写「约」，每个数都能改
- **重新生成**：在 FoodData Central（fdc.nal.usda.gov）的 Download Data 里下载 SR Legacy 的 CSV（几十 MB，不进仓库），运行 `node tools/build-nutrition.mjs <解压出来的目录>`，重写 `src/data/nutrition.js`（重跑结果一样）。挑哪些、叫什么、用 USDA 的哪一条单位在 `tools/nutrition-map.mjs`（一行一样，行尾是 USDA 的原名）；生成的文件里记着对照表和单位规则的指纹，改了对照表没重新生成，测试会失败

## 已知限制

- **不能出现在 iPhone 的分享菜单里**：网页 App 进不了系统的分享菜单，不能从别的 App「分享到 PickNest」。要加东西就打开 PickNest 输入（以后用快捷指令做，见 ROADMAP「以后」）
- **Safari 里的和主屏幕上的不是同一份数据**：在 Safari 标签页里打开的 PickNest 和添加到主屏幕（Mac 上添加到程序坞）的 PickNest 各有各的存储，互相看不到。平时一直用主屏幕上的那个；两边都要用的话开同步。在浏览器标签页里打开时，首页最上面会说一句怎么添加（iPhone、iPad：「分享 → 添加到主屏幕」；Mac 的 Safari：「文件 → 添加到程序坞」；点「知道了」以后这台设备上不再说）。在别的 App 里点开的链接（聊天、邮件 App 自带的浏览器）也能用，只是没网时打不开，数据也是另一份
- **只在 Safari 标签页里用，数据可能被清掉**：Safari（iPhone、iPad、Mac 都一样）会清掉一段时间没打开过的网站存的数据——用着 Safari、大约 7 天没打开 PickNest 就可能清空，事先不提醒。添加到主屏幕 / 程序坞的不受这个限制。所以要添加到主屏幕 / 程序坞来用；只能在标签页里用的话开同步，或者常导出备份
- **删掉主屏幕上的图标，这台设备上的数据也一起删掉**（iPhone、iPad 会清掉这个网页 App 的存储）。删之前先确认同步过（「设置 → 多设备同步」写着「已同步」），或者导出一份备份
- **屏幕常亮要看 iOS 版本**：靠浏览器的屏幕常亮功能（Screen Wake Lock），较旧的 iOS 不支持，有的版本只在 Safari 里有效、主屏幕上的 App 里没效果；低电量模式下也可能不给。不支持时清单页、商店页「⋯」里的「屏幕常亮」那一行会说一句（不是开关），可以在「设置 → 显示与亮度 → 自动锁定」里调长一点
- **同步不是马上的**：改完两秒左右上传，别的设备在打开、切回来、联网时和开着的时候每分钟检查一次，所以要几秒到一分钟才看得到。同一样东西在两台设备上同时改，以后改的那次为准（整条，不是逐个字段合并；例外是一台勾成已买、另一台不知道又改了：买过的还算买过，见上面「多设备同步」）
- **没有 AI 导入**：粘贴文案、截图让 AI 提取要买的东西还没做（见 ROADMAP「以后」），现在一样一样输入（快速添加能直接写数量和单位）。食谱的「粘贴食材」是按规则拆的：认得常见的写法，认不出的整段当名字，看一眼再改；不能贴链接、截图自动读出食谱
- **读写不了 Apple「健康」，也不能扫条形码**：网页 App 拿不到「健康」的数据（要原生 App），记的饮食不会进「健康」，那边的运动消耗也不会算进来；也不能用相机扫包装上的条形码查营养。包装食品照包装上的营养成分表手动填一次，以后从「常吃的」点一下就好
- **营养是自己填的，估算也只是大概**：自动估算按食材的生重和内置的营养表（见上面「自动估算」「营养数据」）算，吸进去的油、做的时候的损耗不算，不认得的食材、「适量」「少许」也不算，和实际吃的可能差 20–30%；要准就照包装、自己称了填
- **计划不会自己跟着食谱变**：食谱改了食材、人数以后，已经生成进清单的用量不会自己变，再「生成购物清单」一次就是新的（替换，不会加成两份）。计划只管食材清单（一般清单上不加）
- **只给一个人用**：没有多人共用、分享清单的功能；同步码里就是令牌，不要给别人
- **不能到店提醒**：网页 App 不能按位置提醒
- **第一次打开要联网**：打开过一次以后整版存在本机，没网也能用。发布了新版：打开 App、切回 App 时（最多半小时一次）在后台下载、校验，下载好了「设置 → 关于」里写着，关掉所有 PickNest 窗口再打开就是新版（下载完之前关掉的话，下次打开再下载）
- **系统空间不够时可能清掉网站数据**：第一次改数据、第一次加成品图时 App 会请浏览器把这里的存储标成「持久的」（主屏幕上的 App 一般直接答应），但还是建议开同步或者常导出备份（备份里没有成品图，图片要靠同步）

## 部署

1. 在 GitHub Desktop 里把这个仓库发布成**公开**仓库 `pick-nest`（GitHub Pages 免费版只支持公开仓库；里面只有程序，没有你的数据）
2. GitHub 上这个仓库的 Settings → Pages：Source 选 `Deploy from a branch`，分支 `main`，目录 `/ (root)`
3. 过一两分钟打开 `https://chizhangrit.github.io/pick-nest/`；iPhone / iPad 上 Safari「分享 → 添加到主屏幕」，Mac 上 Safari「文件 → 添加到程序坞」
4. 以后每次 push，GitHub Pages 自动更新；App 打开、切回来时在后台下载新版，下载好了（「设置 → 关于」里写着）关掉所有 PickNest 窗口再打开就用上

```sh
node scripts/prepare-release.mjs
node --test tests/*.test.mjs
python3 -m http.server 8792 --bind 127.0.0.1
```

然后打开 `http://127.0.0.1:8792`。本地预览用的是独立的浏览器存储，不注册离线缓存（只在 https 下注册），不代表线上已安装的版本。

这台 Mac 的沙盒不让开端口时，用 `swift tools/snapshot.swift 输出.png [--width 390] [--hash '#/settings'] [--theme dark] [--lang en] [--state 编出来的数据.json] [--js '点按钮的脚本']` 在离屏的 WebKit 里打开本地文件截图（说明在脚本开头；只用编出来的数据，截图不进仓库）。

改了图标（`icons/icon.svg`）后运行 `swift tools/render-icons.swift` 重新生成 PNG（只用 macOS 自带的 AppKit），再运行上面的 `prepare-release`。

App 图标和 House Ledger、Virtual Bookshelf、Babble 使用同一套风格：渐变色底、圆润的大图形和奶油白主色。PickNest 用绿色渐变，巢里放着苹果和鸡蛋；SVG 是原稿，180 / 192 / 512px 和 maskable PNG 从它生成。更换图标时同步更新 `index.html` 和两份 manifest 的图标 URL 版本参数，方便系统重新读取。
