# PickNest

购物清单：食材、日用品、衣服、书、木工材料……都放在一个 App 里，可以按清单看，也可以按商店看。去 Whole Foods 前打开「Whole Foods」，所有清单里要在那儿买的东西都在一页上。

- 网页 App（PWA），不需要编译，也不用上架 App Store；部署到 GitHub Pages 就能在 iPhone、iPad、Mac 上用，添加到主屏幕 / 程序坞后和普通 App 一样打开，没网也能用
- 数据保存在自己设备的浏览器里；开启同步后，另存一份到你自己的 GitHub 私有仓库（`pick-nest-data`），不经过任何第三方服务器
- 界面有简体中文、繁體中文（台灣）、English 三种；你写的名字、备注永远原样保存，不做简繁转换

> **正在开发**。进度见 [docs/ROADMAP.md](docs/ROADMAP.md)。标着 🚧 的部分还没做好，下面写的是做好后的样子；做好一部分就把这里改成实际的行为。

> **现在能用的**（第 5 步）：首页「清单」，点进一张清单就能加东西、勾掉、改；能新建、改名、换图标、排顺序、归档、删除清单。「商店」页看每家店还要买几样，点进一家店直接勾。「设置」里能换语言（简体 / 繁體 / English）和外观（自动 / 浅色 / 深色），管理商店和分类，开多设备同步（自己的 GitHub 私有仓库），下载备份、从备份恢复，在「最近删除」里找回删掉的东西。部署后添加到主屏幕，没网也能打开。

## 怎么用

底栏三个：**清单** ｜ **商店** ｜ **设置**。iPad 和 Mac 上换成侧栏。

### 清单

一开始有两张清单：

- **食材**：吃的、喝的、做饭用的。默认在 Whole Foods 买
- **想买**：衣服、书、日用品、工具……不一定马上买的东西也可以先放着

首页每张清单显示还要买几样，点一下进去。右上角「新建清单」：写个名字，选类型（**食材**：常见的东西自动分类；**一般**：多一个「以后再说」，能填链接和价格；类型建好以后不能改），选一个图标（16 个常用的，也可以自己输入一个 emoji），选默认去哪家店买。

- 左上角「编辑」：每张清单右边出现 ↑↓，排顺序
- 清单页右上角「⋯ → 编辑清单」：改名、换图标、换默认商店、归档、删除
- **归档**：不常用的先收起来，在首页最下面「已归档（N）」里，点开、点进去可以取消归档
- **删除**：只有自己建的清单能删，系统自带的两张只能归档。先问一句，删完 10 秒内可以撤销，过了也能在「设置 → 数据 → 最近删除」里恢复；里面的东西跟着隐藏，清单恢复时一起回来

### 加东西

清单页最上面的输入框（往下滚也一直在顶上，返回和「⋯」也是），打字、回车就加好了，输入框留着可以接着加下一样。数量可以直接写在名字前后：

| 输入 | 加进去的是 |
|---|---|
| `牛奶` | 牛奶，1 |
| `鸡蛋 12`、`鸡蛋12个`、`鸡蛋 x12` | 鸡蛋，12（个） |
| `2 牛奶`、`两盒牛奶` | 牛奶，2（盒） |
| `面粉 1袋` | 面粉，1 袋 |
| `半斤肉`、`肉一斤半` | 肉，0.5 斤 / 1.5 斤 |
| `milk 2 gal`、`2 lb beef`、`2 bags of rice` | milk，2 gal / beef，2 lb / rice，2 bags |

- 认得常用的中英文单位（个、袋、盒、瓶、包、斤、磅、lb、oz、g、kg、mL、L、gal、dozen……，繁体、大小写都行）；全角数字、小数、`1/2` 也行。中文数字只在后面跟着单位时才算数量：「五花肉」「三明治」不会被拆开
- 「想买」这类一般清单：光写一个数字不算数量（`iPhone 15`、`100 Years of Solitude` 原样是名字），要写单位或者 x：`袜子 3双`、`电池 x4`、`socks 3 pairs`、`paper 10 sheets`（`pair`、`set`、`sheet` 写在名字前面时要带 of：`3 pairs of socks`；`10 sheet masks` 原样是名字）
- 连着字母的数字是名字的一部分（`维生素B12`、`V8`）；认不出来的整句当名字，加进去以后还能改
- 打字时下面列出以前买过的东西（名字开头就对上的在前，再按常买的、最近买的），旁边是常去的那家店，已经在这张清单上的标着「已在清单上」；点一下就加（输入里写了数量照样用上），Esc 或点别处收起来
- 已经在清单上的东西再加一次，会提示「已经在清单上了」、那一行闪一下，不会重复
- 以前买过、已经清掉的东西再加，就是原来那一条：带上上次的分类、单位、备注
- 商店默认是这样东西**常去的那家**（买的次数最多的；一样多取最近买的；归档的店不算），没买过的用清单的默认商店。这次想换一家买，改这一样就行，不会改掉以后的默认
- 常见的食材会自动分好类（牛奶 → 蛋奶，苹果 → 蔬果，冷冻草莓、冻虾仁 → 冷冻，冻顶乌龙茶、冻干草莓 → 零食饮料；繁体、英文也认得）；分错了改一次，以后都记得（改成「未分类」也记得）。写过的单位也记得（这次写了「面粉 1袋」，下次写「面粉」也是袋）

### 买到了

点一下这一行就勾掉：先在原地打勾、划线，再移到下面的「已买（N）」；在「已买」里再点一下就取消，也是先在原地去掉勾再放回去。挪之前再点一下就是不改了；连着点好几样时，等最后一下之后一起挪；刚挪到手指下面的那一行，紧接着的一下不算（连点两下不会改掉两样）。（系统设了「减少动态效果」时直接移过去。）用键盘、读屏勾掉一样以后，焦点落在顶替它位置的那一样上，可以接着往下勾。

- 勾上半小时内又取消，算点错了（或者最后没买成），不算买过一次；隔久了再从「已买」点回来（又要买了），上次那次照样算在常去的商店里
- 「已买」可以折叠起来（每张清单各自记住）
- 「清除已买」（在「已买」旁边，也在「⋯」菜单里）把已买的都清掉，10 秒内可以撤销
- 「想买」这类一般清单还有「以后再说（N）」：先收着、不算在要买的里面。在编辑面板的「状态」里改

### 改一样东西

点这一行右边的 ›：名字、数量（−/+，空着就是不写数量）、单位（下面有常用单位，点一下填进去）、商店（只改这一次）、分类、备注；清单（换一张就移过去；那张清单上已经有同名的，先问要不要合并成一条）；删除（10 秒内可以撤销）。已买的东西改了名字或商店，买的那一次跟着算到新的上面。一般清单的东西还有状态（要买 / 以后再说 / 已买）、商品链接和价格（链接是手动粘贴的，只收 http / https，「打开」在新标签页打开；现在不会自动读取网页）。点「完成」才保存，有改动时关面板会先问一句。

清单里的东西可以**按分类**或者**按商店**分组（每张清单在这台设备上各自记住），「未分类 / 未指定商店」排在最后，组里按名字排（简体界面按拼音）。不在清单默认商店买的东西标着店名（按商店分组时「要买」的组名就是店，只在「以后再说」「已买」里标）。一般清单里只剩「以后再说」时显示「还没有要买的东西」，不说「都买齐了」。每一行还显示数量、单位和备注的第一行。

### 按商店看

「商店」页列出每家店还要买几样，跨所有清单（只数「要买」的，不算「以后再说」和已买的；归档的清单上的东西也不算）。没有要买的店也列着，数字淡一点；没指定商店的（还有指定的商店删掉了的）在最后的「未指定」里。归档的店还有要买的东西时也列出来，标着「已归档」。右上角「管理商店」直接去「设置 → 商店」。

点进一家店，就是在这家要买的全部东西，按分类分组（和清单页一样），每样标着来自哪张清单（图标 + 名字）。点一下就勾掉（和清单页一样先在原地打勾再挪，这次算在这家店买的），右边的 › 是同一个编辑面板。下面「已买（N）」可以折起来（每家店在这台设备上各自记住），「清除已买」把在这家买到的都清掉，10 秒内可以撤销。

一开始有这些商店：Whole Foods、Trader Joe's、Costco、Target、H Mart、99 Ranch、Amazon、The Home Depot。

- **设置 → 商店**：「新增商店」；每家右边一对 ↑↓ 排顺序（「商店」页和选择列表都按这个顺序；按完页面跟着滚，连着按挪的还是同一家）；点名字（右边有 ›）可以改名（不能和别的店同名）、归档、删除（改了名字还没点「完成」就点归档、删除，先问要不要放弃修改）。归档的不出现在选择里、不当默认，已经指定给它的东西照常显示，收在下面「已归档（N）」里，点开可以取消归档。删除先问一句（说清几样东西会变成「未指定」），10 秒内可以撤销；东西上记着的商店不动，删掉期间显示成「未指定」，商店恢复了就回来。自带的商店也能改名、删除，删掉的不会自己回来
- **设置 → 分类**：分三组——食材（只给食材清单）、一般（只给一般清单）、两边都用。「新增分类」时写名字、选用在哪种清单（建好以后不能改）；组内 ↑↓ 排顺序，就是清单里分组的顺序；点名字可以改名、删除。会出现在同一张清单上的分类不能同名（食材的和一般的可以同名）。自带分类的名字可以清空，就显示自带的名字（跟着界面语言）。删除先问一句，10 秒内可以撤销；分类里的东西归到「未分类」，分类恢复了就回来

### 购物模式 🚧

在清单或者商店页点「开始购物」：字和勾选框更大，已买的收起来，上面显示买了几样、还剩几样，屏幕保持常亮。

### 搜索 🚧

搜所有清单里的东西，简体繁体互通（搜「鸡蛋」也能找到「雞蛋」）。

## 多设备同步

开启后，在任何一台设备上加的、勾的、改的，其它设备打开时都会自动拿到。数据存在你自己的 GitHub 私有仓库 `pick-nest-data` 里（一个文件 `picknest.json`），不经过任何别的服务器；每次同步是一次提交，仓库的历史记录也是一份备份。

首页「清单」标题右边和「设置 → 同步」那一行有一个小标签，说现在的同步状态：已同步（绿点，后面是时间）、待同步 / 同步中 / 离线 / 稍后重试（灰点）、令牌快到期（黄点）、同步出错（红字）、未开同步（空心）。点它去「设置 → 同步」。

### 第一次设置（只需要做一次）

1. 新建一个**私有**仓库 `pick-nest-data`（App 会先确认仓库是私有的，不是私有的不会上传任何东西）：
   - 用 GitHub Desktop：**File → New Repository**，Name 填 `pick-nest-data`，建好后点 **Publish repository**，勾上 **Keep this code private**，再点 Publish
   - 或者在 github.com 右上角 **+ → New repository**，Repository name 填 `pick-nest-data`，选 **Private**
2. 新建一个 Fine-grained 令牌：打开 <https://github.com/settings/personal-access-tokens/new>
   （也就是 GitHub 右上角的**头像 → Settings** → 左侧栏最下面的 **Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**。注意是账号的 Settings，不是仓库里的 Settings）
   - **Token name** 随便起一个认得出来的，比如 `PickNest sync`
   - **Expiration** 选一个有效期（比如 90 天或更长），记下到期日
   - **Repository access** 选 **Only select repositories**，只选 `pick-nest-data`
   - **Permissions → Repository permissions → Contents** 设成 **Read and write**（Metadata 保持 Read-only，别的都不用加；新版页面可能要先点 **Add permissions**）
   - 点 **Generate token**，马上复制生成的令牌（`github_pat_` 开头，离开页面就看不到了）。App 只收 `github_pat_` 开头的：经典令牌（`ghp_` 开头，或者以前那种没有前缀的一长串）不收，它能动你整个 GitHub 账号
3. 打开 App「设置 → 同步」，「第一次设置」里：仓库填 `你的用户名/pick-nest-data`（框里灰色的 `chizhangrit/pick-nest-data` 只是例子，要自己填），粘贴令牌，「令牌到期日」填上第 2 步记下的日子（可以不填，填了会提前两周提醒；连好以后也能在「设置 → 同步」补上，选好日期点「保存到期日」），点「连接」。App 会先检查仓库在不在、令牌能不能看到它、是不是私有的，再马上同步一次；不行的话按钮上面会说原因（仓库名写错了、令牌没选这个仓库、仓库是公开的、令牌过期了……）

### 其它设备

在已经连好的设备上「设置 → 同步」点「复制同步码」（`picknest-sync:` 开头），用隔空投送或者通用剪贴板送到另一台设备，在那台设备的「设置 → 同步」最上面「已经在别的设备上开了同步」粘贴进去：仓库和令牌（那台设备填过到期日的话，到期日也在同步码里）自动填好，点「连接」。iPhone、iPad、Mac 都用**同一个同步码**。同步码里就是令牌原文，只发给自己的设备，不要发到群里。

### 怎么同步

- 改动后两秒左右自动上传（连着改几下只传一次）；切到别的 App、锁屏的时候，有没传的改动马上传
- 打开 App、切回 App（离上次超过 5 秒）、联网时，以及开着的时候每分钟一次，会检查别的设备有没有改过
- 每次先拿别的设备的改动、合并好，再把本机有、云端没有的传上去；没有新改动就不提交
- 几台设备都改过的话逐条合并：每一条（一样东西、一张清单、一家店……）取较新的那次修改。同一样东西在两台设备上同时改，以后改的为准（不是逐个字段合并）。删除也是一样：别的设备上删掉的（包括删掉的自带商店、分类），同步以后这台也删掉，不会自己回来
- 两台设备同时上传撞在一起时，后到的那台会重新拿一次、合并、再传（最多试 4 次，不行就下一轮再来）
- 没网时照常用，改动先存在本机，联网后自动补传。GitHub 说请求太多时，标签显示「稍后重试」，到了它说的时间再自动同步
- 「设置 → 同步」能看到仓库、上次同步时间、有没有还没上传的修改、出错的原因（写成一句话），也可以「立即同步」
- 本机数据坏了、进了恢复页时完全不同步，坏了的数据不会传上去；修好以后接着同步
- 仓库里的 `picknest.json` 就是全部数据（清单、东西、商店、分类、买过的东西的习惯），文件超过 1 MB 也照样能同步。被手动改坏了的话，App 会报错、不会覆盖它；在 GitHub 上把它改回去（或者删掉，下一次同步会重新写一份）就好

### 换令牌、停止同步、安全

- 令牌快到期（两周以内）时，「设置 → 同步」和首页的小标签会提醒（要填了到期日；用带着到期日的同步码连上的设备也会提醒）。在 GitHub 新建一个令牌（权限和原来一样），在一台设备的「设置 → 同步」点「换令牌」粘贴进去、点「保存」，不用停止同步；再点「复制同步码」，在其它每台设备上也点「换令牌」，粘贴这个新的同步码。令牌已经过期或者被删掉了也一样；在换好之前，各台设备照常能用，改动先存在本机，换好后自动补传
- 令牌只保存在这台设备上（本机设置里），不会进备份文件，也不会上传到仓库
- 令牌只能访问 `pick-nest-data` 这一个仓库的内容
- 不想用了：在每台设备上点「停止同步」（先问一句；本机的清单都留着，仓库也不动），再到 GitHub 上删掉这个令牌。以后要再开：在 GitHub 新建一个令牌（「第一次设置」第 2 步），照第 3 步重新连接，再把新的同步码粘贴到其它设备上；只停了一部分设备的话，在还开着的设备上「复制同步码」就行

## 备份与恢复

「设置 → 数据」：

- **下载备份**：一个 JSON 文件 `picknest-backup-年月日.json`，里面是所有清单、东西、商店、分类和买过的东西的习惯（「最近删除」里的也在）。没有同步令牌，也没有这台设备的设置（语言、外观、各清单的显示方式）。能用系统分享的浏览器上（iPhone、iPad，还有 Mac 上的 Safari）还有「分享备份…」，可以存到「文件」或者隔空投送到别的设备。下面写着这台设备上次备份是什么时候
- **从备份恢复…**：选一个备份文件，先告诉你里面有几张清单、几样东西、是什么时候的，确认后**合并**：每一条取较新的，这台设备上有、备份里没有的不会被删掉；完了说改了几条（备份里没有更新的就什么也不改）。开着同步时，合并的结果马上同步到别的设备。不是 PickNest 的文件、读不出来的文件、新版 App 做的备份都会直接说清楚，不会动现有的数据。同步仓库里的 `picknest.json`、出错时下载的原始数据也能拿来恢复
- **恢复前的原始数据**：在恢复页修过本机数据以后才有，下载修之前存下的原件（排查问题用，里面没有同步令牌）

### 本机数据损坏时

本机存的数据读不出来时，App 会盖上一个恢复页，暂停修改和同步，不会把坏了的数据当成空白的清单继续保存。可以：

- 「下载原始数据」：先留一份原件（里面没有同步令牌）
- 「重新读取」：存储临时出问题（比如权限）时再读一次
- 「从备份恢复」：选一个备份文件
- 「从云端恢复」（开过同步才有）：只读地取仓库里现在的那一份。令牌过期了取不到时会说一声：先「保留读得出来的部分」，再去「设置 → 同步」换令牌，换好以后云端的那一份照样会合并进来
- 「保留读得出来的部分，继续使用」

后三个都会先确认，把选的数据和读得出来的部分逐条合并；替换之前先把原件存档（之后在「设置 → 数据」里还能下载），存档或写入失败时不会清掉原件。修好以后同步照常，合并的结果会传上去。

## 最近删除

删掉的清单、东西、商店、分类都在「设置 → 数据 → 最近删除」里，按种类分组，新删的在前，每一项旁边有「恢复」。删除一律只是做个标记，内容一直留着（也照样同步），所以过多久都能恢复；恢复也会同步到别的设备。

- 删掉的清单里的东西不单列：恢复清单时一起回来（那一行写着有几样）。在清单删掉之前就分开删掉的东西，等清单恢复了再单独恢复
- 「清除已买」清掉的东西也在这里（标着「已买」），恢复后回到那张清单的「已买」里；以后再加同名的东西，也会直接恢复那一条
- 清单上已经有同名的东西、已经有同名的商店或者会一起出现的同名分类时不能恢复（会说一声，东西会说是哪张清单上的），先把现在那个改个名字
- 东西很多时先列 50 样，下面「再显示」
